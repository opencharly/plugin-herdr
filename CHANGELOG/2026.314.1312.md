# 2026.314.1312 — refactor(schema): derive the herdr word sets from vocabulary tables

## Summary

Convert the three inline `|` word unions in `candy/plugin-herdr/schema/herdr.cue`
to the §10.1 S3 vocabulary-table idiom, so each closed set of words has ONE home
and the enum an author meets is `or()` of that table's keys:

```
_method  _source  _until      (+ _methodWord / _sourceWord / _untilWord)
```

That is the 3 `union` rows `design/dpat-baseline.tsv` records for
`plugin-herdr/candy/plugin-herdr/schema/herdr.cue` — three disjunctions, one row
each, all three pure word lists. The `@go(...)` attribute on each field is kept
verbatim, so the generated Go keeps its shape; the ONLY line the projection changes
is the `method` doc comment, which now states the derivation.

**How this repo was picked.** It is the second unit of the sequence, taken from the
entirely-word-list set re-derived in the first unit. The ranking that produced that
set, from `origin/main`'s census:

hand-written literal that happens to equal the table: every set- and probe-based check

author meets must then accept the injected word.
