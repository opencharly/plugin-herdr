# 2026.245.0859 — feat: herdr plugin — command:herdr CLI + herdr: check verb over the NDJSON socket API

## Summary

New plugin repo `opencharly/plugin-herdr`: the charly **herdr** plugin — a
`command:herdr` CLI plus the declarative `verb:herdr` check verb for a Herdr
terminal-multiplexer session (herdr.dev), speaking the herdr NDJSON socket API
directly (no upstream `herdr` binary dependency).

- **Command tree** (`charly herdr`): `status`, `session snapshot`,
  `workspace list|create`, `tab list|create`, `pane list|split|run|read|send-text|send-keys|wait-output`,
  `agent list|get|wait|prompt|report`, `config`.
- **Check verb** (`herdr:`): `ping`, `session-snapshot`, `workspace-list`,
  `tab-list`, `pane-list`, `agent-list`, `pane-wait-output`, `agent-wait`, `agent-prompt`
  — the bed surface; resolves the in-venue socket bridge over the reverse channel.
- **R3 single surface**: one Go NDJSON client (dial-per-call, matching the live
  server's one-request-per-connection behavior) serves both placements.
- **Safety boundary as code** (herdr agent-skill rule): the focused session is
  OFF-LIMITS unless `HERDR_ENV=1`, `--focused`, or an explicit
  `--session`/`--endpoint`/`HERDR_SOCKET_PATH` target is given.
- `schema/herdr.cue` → generated `params/cue_types_gen.go` (`cue exp gengotypes`).
- `skill:` entity `herdr` (family `automation`) for the marketplace corpus.
- Org-standard repo meta: discover-project root charly.yml, candy CI gate
  (pinned charly submodule build + `box validate` + Go build/tests),
  `charly/pr-validator` + `tag-on-merge` dispatchers.

The plugin wire contract was mined from the live herdr 0.8.2 API schema
(`herdr api schema --json`, protocol 20) and pinned by fake-socket tests.
