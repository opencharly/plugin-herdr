# 2026.245.0907 — fix: normalize --endpoint spellings (accept tcp://host:port and host:port)

## Summary

Bugfix found by the check-herdr-pod live bed: `resolveTarget` double-prefixed the
`--endpoint` value when the caller passed the documented `tcp://host:port` spelling
(`tcp://tcp://host:port` — "too many colons in address", `charly herdr` exit 1).
Now trims a leading `tcp://` before prefixing, so both `host:port` and
`tcp://host:port` work. Adds endpoint-spelling + focused-guard unit tests
(`session_test.go`).
